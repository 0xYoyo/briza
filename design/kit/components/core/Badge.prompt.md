One-line: static pill for one short fact — size range, price-from, stock note — used in rows of two or three, never as a link or button.

```jsx
<Badge tone="sand" icon="ruler">מידות 38–54</Badge>
<Badge tone="ice" icon="tag">מ־₪79</Badge>
```

Notes
- Text only: a number, a range, or two or three Hebrew words. No sentences.
- `coral` is reserved for a genuine sale/discount; using it decoratively cheapens it.
- Font is body semibold at 18px so it stays readable for the 50+ audience.
