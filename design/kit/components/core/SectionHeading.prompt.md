One-line: opens every page section with an optional eyebrow, a display-font h2, and one supporting sentence.

```jsx
<SectionHeading eyebrow="הסיפור שלנו" title="ארבעים שנה באותה פינה" lead="בריזה נפתחה ב-1986…" />
```

Notes
- One heading per section; the eyebrow replaces a second heading level.
- Keep `lead` to a single sentence on mobile — long leads push the WhatsApp button below the fold.
- `tone="dark"` switches the eyebrow to ice-blue for navy sections.
